# 🤖 ABM1213 Assistant IA

Un assistant intelligent développé en Python avec **Gemini API** et **Streamlit**, capable d'exécuter des outils système et de gérer vos tâches au quotidien.

## ✨ Fonctionnalités
- 💬 **Conversation IA** : Basée sur les modèles Gemini (`gemini-1.5-flash` / `gemini-3.8-flash`).
- 📝 **Gestion de tâches** : Ajout, affichage, validation et suppression (`tasks.json`).
- 🛠️ **Outils système** : Lecture/création de fichiers, statut Git, heure système.
- 🌤️ **Météo** : Consultation de la météo en direct.
- 🎨 **Interface Web** : Développée avec Streamlit.
